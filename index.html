📌 About the Project

Personal Expense Tracker is a beginner-friendly Python desktop project designed to make recording and reviewing daily expenses simple.

🛠️ Technologies

Python Tkinter Treeview GUI

✨ Features

  • ➕ Add and record expenses
  • 📋 Display expenses in an organized table
  • 🏷️ Categorize expenses
  • 💵 Calculate the total expenses
  • 🖥️ User-friendly graphical interface
